Les Tableaux en Java

1️⃣ Qu’est-ce qu’un tableau ?

Un tableau permet de stocker plusieurs valeurs du même type dans une seule variable.

Chaque valeur est accessible grâce à un indice qui commence toujours par 0.

2️⃣ Déclaration d’un tableau


int[] notes = new int[5];

3️⃣ Initialisation d’un tableau


int[] notes = {12, 15, 9, 18, 14};

4️⃣ Accéder aux éléments


int[] notes = {12, 15, 9};

System.out.println(notes[0]); // 12
System.out.println(notes[1]); // 15
System.out.println(notes[2]); // 9

5️⃣ Parcourir un tableau avec une boucle


int[] notes = {12, 15, 9, 18};

for (int i = 0; i < notes.length; i++) {
    System.out.println(notes[i]);
}

6️⃣ La propriété length

length permet de connaître le nombre d’éléments dans un tableau. 


int taille = notes.length;
System.out.println(taille);
À retenir :
✔ Les indices commencent à 0
✔ Tous les éléments ont le même type
✔ Les tableaux fonctionnent très bien avec les boucles

  1. Créer un tableau de 5 notes
  2. Afficher toutes les notes
  3. Calculer la moyenne
  4. Afficher la note maximale

Notes :
12
15
9
18
14

Moyenne : 13.6
Note maximale : 18

  • Compter le nombre de notes ≥ 10

  • Améliorer l’affichage avec des messages clairs
