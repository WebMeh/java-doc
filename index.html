Introduction à Java

Java est un langage de programmation orienté objet, robuste et très utilisé dans le développement d’applications professionnelles.

Pourquoi apprendre Java ?

  • Langage très demandé sur le marché
  • Multi-plateforme
  • Utilisé dans le web, mobile, desktop

Premier programme Java


public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java !");
    }
}
À retenir : Le point d’entrée d’un programme Java est la méthode main.
