Chapitre 1 : Bases Java

1️⃣ Qu’est-ce que Java ?

Java est un langage de programmation orienté objet, créé en 1995 par James Gosling. Il est très utilisé dans le développement d’applications professionnelles.

2️⃣ Environnement de travail

  • JDK (Java Development Kit)
  • Un éditeur de code (VS Code, IntelliJ, Eclipse)

3️⃣ Structure d’un programme Java


public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour Java !");
    }
}

4️⃣ Explication du code

  • class : définit une classe
  • main : point de départ du programme
  • System.out.println : affiche un message
À retenir :
Le nom du fichier doit être identique au nom de la classe.

6️⃣ Règles de base

  • Java est sensible à la casse
  • Chaque instruction se termine par ;
  • Les blocs utilisent { }

7️⃣ Commentaires en Java


// Commentaire sur une ligne

/*
   Commentaire
   sur plusieurs lignes
*/
