Programmation Orientée Objet (POO) en Java

1️⃣ Qu’est-ce que la POO ?

La Programmation Orientée Objet (POO) est une manière de programmer basée sur des objets représentant des éléments du monde réel.

En Java, tout est basé sur les classes et les objets.

2️⃣ La notion de classe

Une classe est un modèle (plan) qui décrit un objet. 


class Etudiant {
    String nom;
    int age;
}

3️⃣ La notion d’objet

Un objet est une instance d’une classe. 


Etudiant e1 = new Etudiant();
e1.nom = "Ali";
e1.age = 18;

4️⃣ Les attributs

Les attributs sont des variables qui décrivent les caractéristiques d’un objet. 


class Voiture {
    String marque;
    int vitesse;
}

5️⃣ Les méthodes dans une classe

Une méthode définit le comportement d’un objet. 


class Voiture {
    String marque;
    int vitesse;

    void accelerer() {
        vitesse = vitesse + 10;
    }
}

6️⃣ Le constructeur

Le constructeur permet d’initialiser un objet lors de sa création. 


class Etudiant {
    String nom;
    int age;

    Etudiant(String n, int a) {
        nom = n;
        age = a;
    }
}

7️⃣ Utilisation d’une classe (main)


public class Main {
    public static void main(String[] args) {
        Etudiant e1 = new Etudiant("Sara", 19);
        System.out.println(e1.nom);
        System.out.println(e1.age);
    }
}
