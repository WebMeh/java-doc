Chapitre 2 : Variables & Types

1️⃣ Qu’est-ce qu’une variable ?

Une variable est un espace mémoire qui permet de stocker une valeur (nombre, texte, etc.). 


int age = 20;
  • age : est le nom de la variable
  • int : est le type
  • 20 : est la valeur

2️⃣ Déclaration et affectation


int nombre;
nombre = 10;

Ou en une seule ligne :


int nombre = 10;

3️⃣ Types de données primitifs

Type Description Exemple
int Nombre entier int age = 18;
double Nombre décimal double prix = 19.5;
char Caractère char genre = 'M';
boolean Vrai / Faux boolean actif = true;

4️⃣ Type String (texte)


String nom = "Rachid";
String ville = "Azilal";

⚠ String commence par une majuscule car c’est une classe.

5️⃣ Concaténation


String nom = "Ali";
int age = 20;

System.out.println("Nom : " + nom);
System.out.println("Âge : " + age);

6️⃣ Exemple complet


public class Main {
    public static void main(String[] args) {

        String nom = "Sara";
        int age = 22;
        double moyenne = 14.5;
        boolean admis = true;

        System.out.println("Nom : " + nom);
        System.out.println("Âge : " + age);
        System.out.println("Moyenne : " + moyenne);
        System.out.println("Admis : " + admis);
    }
}
À retenir :
✔ Une variable stocke une valeur
✔ Chaque variable a un type
✔ String sert à stocker du texte
✔ Le symbole + permet la concaténation

Exercice pratique : Fiche Élève

Cet exercice vous permettra de pratiquer l’utilisation des variables et des types de données en Java.

Écrire un programme Java qui représente la fiche d’un élève.

Le programme doit :

  1. Déclarer les variables suivantes :
  • nom : String
  • prenom : String
  • age : int
  • note : double
  • genre : char
  • admis : boolean

Puis afficher le résultat sous la forme suivante : 


----- FICHE ELEVE -----
Nom       : Naoui
Prénom    : Said
Âge       : 18 ans
Note      : 14.5
genre      : F
Admis     : true
