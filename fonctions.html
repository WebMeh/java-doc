Les Fonctions (Méthodes) en Java

1️⃣ Qu’est-ce qu’une méthode ?

Une méthode est un bloc de code nommé qui permet de réaliser une tâche précise.

Elle permet de rendre le programme plus clair, organisé et réutilisable.

2️⃣ Structure d’une méthode


typeRetour nomMethode(paramètres) {
    // instructions
}

3️⃣ Méthode sans valeur de retour (void)


static void afficherMessage() {
    System.out.println("Bienvenue en Java");
}

4️⃣ Méthode avec valeur de retour


static int addition(int a, int b) {
    return a + b;
}

5️⃣ Appel d’une méthode


int resultat = addition(4, 6);
System.out.println(resultat);

6️⃣ Paramètres d’une méthode

Les paramètres permettent de transmettre des valeurs à une méthode. 


static void afficherNom(String nom) {
    System.out.println("Bonjour " + nom);
}
