Projet 1 : Gestion de la Coupe d’Afrique

Contexte

Vous êtes membre du comité technique de la Coupe d’Afrique des Nations. Votre mission est de développer un programme Java permettant de gérer les équipes participantes.

Contraintes pédagogiques

  • ❌ Pas de programmation orientée objet
  • ✅ Tableaux + fonctions uniquement
  • ✅ Utilisation de Scanner
  • ✅ Menu interactif

Données à gérer

  • Nom de l’équipe
  • Pays
  • Nombre de points

👉 Chaque équipe sera stockée à l’aide de tableaux parallèles. 

String[] noms = new String[24];
String[] pays = new String[24];
int[] points = new int[24];

Fonctions à développer

  1. ajouterEquipe()
  2. afficherEquipes()
  3. rechercherEquipe(String nom)
  4. modifierPoints()
  5. supprimerEquipe()
  6. menu()

Menu attendu

1. Ajouter une équipe
2. Afficher les équipes
3. Modifier les points
4. Supprimer une équipe
0. Quitter

Défis

  • Empêcher l’ajout de plus de 24 équipes
  • Empêcher les points négatifs
  • Afficher le classement par points
  • Répéter le menu tant que l’utilisateur ne quitte pas
💡 Astuce :
Ce projet sera refactorisé plus tard en version POO avec une classe Equipe.
