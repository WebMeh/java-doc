Chapitre : Input / Output en Java

Objectifs

  • Afficher des informations à l’écran
  • Lire des données saisies par l’utilisateur

1️⃣ Output : Affichage à l’écran

En Java, l’affichage à l’écran se fait avec System.out.println(). 


System.out.println("Bonjour Java");
System.out.println("Bienvenue au cours");

2️⃣ Différence entre print et println


System.out.print("Bonjour ");
System.out.print("Java");

==> print n’effectue pas de retour à la ligne
==> println passe à la ligne automatiquement

3️⃣ Input : Lire des données utilisateur

Pour lire des données saisies au clavier, on utilise la classe Scanner.

4️⃣ Import de Scanner


import java.util.Scanner;

Cette ligne permet d’utiliser la classe Scanner dans le programme.

5️⃣ Lire une chaîne de caractères


import java.util.Scanner;

public class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Entrez votre nom : ");
        String nom = sc.nextLine();

        System.out.println("Bonjour " + nom);
    }
}

6️⃣ Lire un nombre


System.out.print("Entrez votre âge : ");
int age = sc.nextInt();

System.out.println("Votre âge est : " + age);
À retenir :
✔ nextLine() → texte
✔ nextInt() → entier
✔ nextDouble() → nombre décimal

7️⃣ Exemple complet Input / Output


import java.util.Scanner;

public class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Nom : ");
        String nom = sc.nextLine();

        System.out.print("Âge : ");
        int age = sc.nextInt();

        System.out.println("Bienvenue " + nom + ", âge : " + age);
    }
}
