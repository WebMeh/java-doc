Projet Final – Application Java Swing & SQLite

Ce projet marque la fin du module Java Swing. Vous allez développer une application complète avec interface graphique connectée à une base de données SQLite.

Important : Chaque groupe choisit son propre thème (gestion d’élèves, bibliothèque, produits, employés, films, clients, etc.). Le sujet est libre, mais la structure technique doit respecter les exigences ci-dessous.

Objectif Technique :

Créer une application capable de gérer des données : ajouter, afficher, modifier et supprimer des informations stockées dans une base SQLite.

Programmation Orientée Objet (POO) :

Ce projet doit obligatoirement respecter les principes de la programmation orientée objet.

Exigence minimale :

  • L’application doit contenir au moins 2 classes Java.
  • Une classe pour représenter les données (ex : Etudiant, Produit, Client…).
  • Une classe pour gérer l’interface graphique (JFrame).

Exemple d’organisation (à adapter selon votre thème)

Classe Rôle
Model (ex: Etudiant.java) Contient les attributs (nom, prénom, etc.)
Interface (ex: MainFrame.java) Contient le JFrame, les JPanel, les boutons et le JTable

💡 Bonus : Les groupes avancés peuvent ajouter une 3ème classe pour la gestion de la base de données (DAO).

Fonctionnalités obligatoires :

  • Ajouter un enregistrement
  • Modifier un enregistrement
  • Supprimer un enregistrement
  • Afficher les données dans un JTable
  • Vider les champs du formulaire (bouton Annuler)

Interface Graphique Attendue :

  • Une fenêtre principale (JFrame)
  • Un formulaire de saisie (JLabel + JTextField ou autres composants)
  • Des boutons d’action :
    • Ajouter
    • Modifier
    • Supprimer
    • Annuler
  • Un JTable pour afficher les données enregistrées
  • Une organisation propre avec des JPanel et des Layouts

Base de Données :

L’application doit utiliser SQLite pour stocker les données. La table doit contenir :

  • Un identifiant (ID).
  • Au moins 3 autres champs selon votre thème.

Comportement attendu :

Action utilisateur Résultat attendu
Clic sur Ajouter Les données sont enregistrées dans SQLite + tableau mis à jour
Clic sur une ligne du tableau Les informations apparaissent dans le formulaire
Clic sur Modifier Les données sont mises à jour dans la base
Clic sur Supprimer L’enregistrement est supprimé de la base
Clic sur Annuler Les champs du formulaire sont vidés

Qualité de l’interface :

  • Interface claire et organisée
  • Utilisation correcte des Layouts
  • Espaces entre les composants
  • Design agréable (couleurs légères, alignement)

Résultat Final Attendu :

À la fin, votre application doit :

  • Fonctionner sans erreur.
  • Être connectée à une base SQLite.
  • Afficher et gérer les données dans un JTable.
  • Avoir une interface professionnelle.
