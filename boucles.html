Les Boucles

1️⃣ Qu’est-ce qu’une boucle ?

Une boucle permet de répéter automatiquement un bloc de code plusieurs fois, sans le réécrire.

Elle est utilisée lorsqu’une action doit être répétée selon une condition ou un nombre précis de fois.

2️⃣ La boucle for

La boucle for est utilisée lorsque le nombre de répétitions est connu à l’avance. 


for (int i = 0; i < 5; i++) {
    System.out.println("Tour numéro " + i);
}

3️⃣ La boucle while

La boucle while répète le code tant qu’une condition est vraie. 


int compteur = 1;

while (compteur <= 3) {
    System.out.println("Compteur : " + compteur);
    compteur=compteur+1;
}

4️⃣ La boucle do...while

La boucle do...while s’exécute au moins une fois, même si la condition est fausse. 


int choix;

do {
    System.out.println("Menu affiché");
    choix++;
} while (choix < 1);

5️⃣ Comparaison des boucles

Boucle Utilisation
for Nombre de répétitions connu
while Condition vérifiée avant l’exécution
do...while Exécution au moins une fois
À retenir :
✔ Une boucle évite la répétition du code
✔ Le choix de la boucle dépend du problème à résoudre

Exercice : Jeu de score (boucles)

  1. Initialiser un score à 0
  2. Afficher le score actuel
  3. Demander à l’utilisateur s’il veut continuer (O/N)
  4. Ajouter 10 points à chaque tour
  5. Répéter tant que l’utilisateur répond O

Exemple d’exécution

Score actuel : 0
Continuer le jeu ? (O/N) : O

Score actuel : 10
Continuer le jeu ? (O/N) : O

Score actuel : 20
Continuer le jeu ? (O/N) : N

Score final : 20

Défi

  • Limiter le jeu à 10 tours maximum
  • Afficher un message spécial si score ≥ 50
  • Proposer de rejouer à la fin
