JLabel & JTextField – Composants de base

Les composants JLabel et JTextField sont utilisés pour afficher du texte et permettre la saisie utilisateur dans une interface Swing.

1️⃣ JLabel

JLabel sert à afficher du texte non modifiable. Il peut aussi afficher des images.

Propriétés essentielles :

Propriété Description
text Le texte affiché par le label
foreground Couleur du texte (setForeground(Color))
font Police du texte (setFont(new Font("Arial", Font.BOLD, 14)))
horizontalAlignment Alignement horizontal du texte (SwingConstants.LEFT / CENTER / RIGHT)

2️⃣ JTextField

JTextField permet à l’utilisateur de saisir du texte sur une seule ligne.

Propriétés essentielles :

Propriété Description
text Le texte initial du champ (getText() / setText())
columns Nombre de colonnes pour déterminer la largeur
editable Si le texte peut être modifié (true / false)
foreground / background Couleur du texte et du fond (setForeground(Color), setBackground(Color))

Exemple pratique – Petit formulaire


import javax.swing.*;
import java.awt.*;

public class FormExample {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Formulaire simple");
        frame.setSize(400, 200);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new FlowLayout());

        // JLabel et JTextField
        JLabel labelName = new JLabel("Nom :");
        JTextField textName = new JTextField(15);

        JLabel labelEmail = new JLabel("Email :");
        JTextField textEmail = new JTextField(15);

        // Ajouter au frame
        frame.add(labelName);
        frame.add(textName);
        frame.add(labelEmail);
        frame.add(textEmail);

        frame.setVisible(true);
    }
}
À retenir : JLabel sert à afficher du texte ou une image, tandis que JTextField permet de saisir du texte. Utilisez les propriétés pour personnaliser l'apparence.
