Les Tableaux en Swing – JTable

Le composant JTable permet d’afficher des données sous forme de lignes et colonnes, comme dans Excel.

1️⃣ Structure d’un JTable

Un tableau Swing a besoin de :

  • Les noms des colonnes
  • Les données (lignes du tableau)

Définir les colonnes

String[] colonnes = {"ID", "Nom", "Age"};

Définir les données

Object[][] donnees = {
    {1, "Ali", 20},
    {2, "Sara", 22},
    {3, "Youssef", 19}
};

2️⃣ Créer le JTable

JTable table = new JTable(donnees, colonnes);

⚠️ Un JTable doit être placé dans un JScrollPane :

JScrollPane scrollPane = new JScrollPane(table);

3️⃣ Exemple Complet

import javax.swing.*;

public class TableauSimple {
    public static void main(String[] args) {

        JFrame frame = new JFrame("Exemple JTable");
        frame.setSize(500, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        String[] colonnes = {"ID", "Nom", "Age"};

        Object[][] donnees = {
            {1, "Ali", 20},
            {2, "Sara", 22},
            {3, "Youssef", 19}
        };

        JTable table = new JTable(donnees, colonnes);
        JScrollPane scrollPane = new JScrollPane(table);

        frame.add(scrollPane);
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);
    }
}

4️⃣ Lire une valeur du tableau

int ligne = table.getSelectedRow();
int colonne = table.getSelectedColumn();

Object valeur = table.getValueAt(ligne, colonne);
System.out.println("Valeur sélectionnée : " + valeur);

5️⃣ Personnaliser le tableau

Changer la hauteur des lignes

table.setRowHeight(30);

Modifier la largeur des colonnes

table.getColumnModel().getColumn(0).setPreferredWidth(50);
table.getColumnModel().getColumn(1).setPreferredWidth(150);
table.getColumnModel().getColumn(2).setPreferredWidth(50);

6️⃣ Empêcher la modification des cellules

JTable table = new JTable(donnees, colonnes) {
    public boolean isCellEditable(int row, int column) {
        return false;
    }
};

💡 Astuce (Bonus) : Permettez à l’utilisateur de cliquer sur une ligne du tableau et d’afficher le prénom de l’élève sélectionné dans la console ou dans un JLabel.

Indications :

  • Utiliser getSelectedRow() pour récupérer la ligne choisie
  • Utiliser getValueAt(ligne, colonne) pour lire la valeur
  • La colonne Prénom correspond à son index (ex: 2)
