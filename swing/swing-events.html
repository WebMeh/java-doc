Les événements en Swing

Une interface graphique n’est utile que si elle peut réagir aux actions de l’utilisateur. Ces actions sont appelées des événements.

🔹 Qu’est-ce qu’un événement ?

Un événement est une action réalisée par l’utilisateur, par exemple :

  • Cliquer sur un bouton
  • Cocher une case
  • Sélectionner un bouton radio
  • Écrire dans un champ texte
Important : Sans événements, une interface graphique ne fait rien.

🔹 Principe général

En Swing, le fonctionnement est toujours le même :

  1. L’utilisateur effectue une action
  2. Le composant détecte cette action
  3. Le programme exécute du code en réponse

Pour écrire ce code de réaction, nous utilisons la forme suivante : 


composant.addActionListener(e -> {
    // code à exécuter
});

🔹 Exemple avec JButton


JButton btn = new JButton("Cliquer");

btn.addActionListener(e -> {
    System.out.println("Bouton cliqué !");
});

Ici :

  • addActionListener permet d’écouter l’action
  • e représente l’événement déclenché
  • Le code s’exécute automatiquement au clic

🔹 Exemple avec JCheckBox


JCheckBox cb = new JCheckBox("Accepter les conditions");

cb.addActionListener(e -> {
    System.out.println("État changé");
});

Chaque fois que l’état de la case change (coché / décoché), le code est exécuté.

🔹 Exemple avec JRadioButton


JRadioButton rbHomme = new JRadioButton("Homme");

rbHomme.addActionListener(e -> {
    System.out.println("Homme sélectionné");
});

🔹 Lire des valeurs depuis un champ texte


JTextField tfNom = new JTextField(15);
JButton btnAfficher = new JButton("Afficher");

btnAfficher.addActionListener(e -> {
    String nom = tfNom.getText();
    System.out.println(nom);
});
À retenir : Les événements permettent de récupérer les données saisies par l’utilisateur.

Exercice – Formulaire de contact interactif

Objectif : Rendre le formulaire de contact du chapitre précédent interactif en utilisant les événements Swing.

Consigne : Reprenez le formulaire de contact que vous avez déjà créé (Nom, Prénom, Email, Sexe, Centres d’intérêt, Message, boutons). Ajoutez maintenant des événements aux boutons Valider et Annuler.

🔹 Bouton « Valider » :

  1. Ajouter un événement sur le bouton Valider.
  2. Lors du clic :
    • Récupérer le texte des champs : Nom, Prénom, Email et Message.
    • Déterminer le sexe sélectionné (Homme ou Femme).
    • Vérifier les centres d’intérêt cochés.
    • Afficher toutes les informations dans la console.

🔹 Bouton « Annuler » :

  1. Ajouter un événement sur le bouton Annuler.
  2. Lors du clic :
    • Vider tous les champs texte.
    • Vider la zone de message.
    • Remettre le sexe par défaut à Homme.
    • Décocher toutes les cases des centres d’intérêt.

💡 Astuces

  • getText(): permet de récupérer le contenu d’un champ texte.
  • setText(""): permet de vider un champ.
  • isSelected(): permet de vérifier si un bouton est coché.
  • setSelected(true / false): permet de modifier la sélection.
  • Utiliser uniquement la forme : 
    
addActionListener(e -> {
    // code à exécuter
});

Résultat attendu :
✔ Le bouton Valider affiche les données du formulaire.
✔ Le bouton Annuler réinitialise entièrement le formulaire.
