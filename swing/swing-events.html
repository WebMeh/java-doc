Événements Swing

En Java Swing, un événement est une action déclenchée par l’utilisateur ou le système, comme cliquer sur un bouton, taper au clavier ou fermer une fenêtre.

1️⃣ Les composants générant des événements

  • JButton → clic sur le bouton
  • JTextField → entrée de texte + touche Entrée
  • JCheckBox → sélection / désélection
  • JRadioButton → sélection d’option
  • JComboBox → choix dans une liste déroulante

2️⃣ L’interface ActionListener

Pour gérer un événement de clic sur un bouton, on utilise l’interface ActionListener. Elle possède une seule méthode : 

void actionPerformed(ActionEvent e)

Exemple simple :

import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

JFrame frame = new JFrame("Exemple ActionListener");
frame.setSize(300, 200);
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setLayout(new FlowLayout());

JButton btnClick = new JButton("Cliquez-moi");

// Ajouter un ActionListener
btnClick.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        JOptionPane.showMessageDialog(frame, "Vous avez cliqué sur le bouton !");
    }
});

frame.add(btnClick);
frame.setVisible(true);

3️⃣ Tableau récapitulatif des événements

Composant Événement Interface
JButton Clic ActionListener
JTextField Entrée texte + Enter ActionListener
JCheckBox Check / Uncheck ItemListener
JRadioButton Sélection ItemListener
JComboBox Choix dans la liste ActionListener
À retenir : Pour chaque événement, il faut :
  1. Choisir le composant
  2. Implémenter l’interface correspondante
  3. Écrire la méthode qui sera exécutée
  4. Attacher le listener au composant

Exercice d'application :

  1. Créer une fenêtre JFrame de taille 300x200
  2. Ajouter un JButton intitulé "Cliquez-moi"
  3. Ajouter un ActionListener au bouton
  4. Dans actionPerformed, afficher un message avec JOptionPane.showMessageDialog indiquant "Vous avez cliqué sur le bouton !"
  5. Tester le bouton plusieurs fois

💡 Astuce : utilisez un FlowLayout pour centrer le bouton dans la fenêtre.
