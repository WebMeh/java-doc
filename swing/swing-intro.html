Introduction à GUI Swing

Swing est une bibliothèque graphique de Java qui permet de créer des applications avec interface graphique (fenêtres, boutons, champs de saisie, menus, etc.).

Qu’est-ce qu’une GUI ?

Une GUI (Graphical User Interface) est une interface visuelle qui permet à l’utilisateur d’interagir avec le programme à l’aide de la souris et du clavier.

  • Boutons
  • Champs de texte
  • Fenêtres
  • Boîtes de dialogue

Swing :

Swing est une bibliothèque intégrée à Java qui permet de créer des applications graphiques multiplateformes.

  • Fonctionne sur Windows, Linux et macOS.
  • Basée sur la programmation orientée objet.
  • Utilisée dans les projets desktop.
À retenir : Swing fonctionne avec des composants et des événements. Tout commence par une fenêtre JFrame.
