JFrame – La fenêtre principale

JFrame est le composant principal de Swing. Il représente la fenêtre de l’application graphique. Toute application Swing commence par une fenêtre.

Objectif de ce chapitre

  • Comprendre le rôle de JFrame
  • Savoir créer une fenêtre Swing
  • Connaître les propriétés essentielles d’une fenêtre
  • Afficher correctement une application graphique

Qu’est-ce qu’un JFrame ?

Un JFrame est une fenêtre avec une barre de titre, des boutons (réduire, agrandir, fermer) et une zone de travail dans laquelle on place les composants graphiques.

Création d’une fenêtre :


import javax.swing.*;

public class Main {
    public static void main(String[] args) {

        JFrame frame = new JFrame("Azicode62 App");

        frame.setSize(400, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}

Propriétés essentielles d’un JFrame

Propriété / Méthode Description
setTitle(String) Définit le titre de la fenêtre
setSize(int, int) Définit la largeur et la hauteur
setLocationRelativeTo(null) Centre la fenêtre à l’écran
setResizable(boolean) Autorise ou non le redimensionnement
setDefaultCloseOperation() Définit l’action à la fermeture
setVisible(boolean) Affiche ou masque la fenêtre

Exemple :


JFrame frame = new JFrame();
frame.setTitle("Application Azicode62");
frame.setSize(500, 400);
frame.setLocationRelativeTo(null);
frame.setResizable(false);
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setVisible(true);
À retenir : Sans setVisible(true), la fenêtre ne s’affiche jamais. La classe JFrame est toujours le point de départ d’une GUI Swing.
