Les alertes et boîtes de dialogue avec Swing

Swing permet d’afficher des fenêtres de message appelées boîtes de dialogue. Elles servent à informer l’utilisateur, poser une question ou demander une saisie.

🔹 Classe utilisée : JOptionPane

Toutes les alertes simples en Swing sont gérées avec la classe : 

JOptionPane
Important : Une boîte de dialogue bloque le programme jusqu’à ce que l’utilisateur réponde.

🔹 1. Message d'information


JOptionPane.showMessageDialog(null, "Opération réussie !");

Affiche un message simple avec un bouton OK.

🔹 2. Message d’erreur


JOptionPane.showMessageDialog(null,
    "Une erreur est survenue",
    "Erreur",
    JOptionPane.ERROR_MESSAGE);

🔹 3. Message d’avertissement


JOptionPane.showMessageDialog(null,
    "Attention à cette action",
    "Avertissement",
    JOptionPane.WARNING_MESSAGE);

🔹 4. Boîte de confirmation (Oui / Non)


int choix = JOptionPane.showConfirmDialog(null,
    "Voulez-vous continuer ?",
    "Confirmation",
    JOptionPane.YES_NO_OPTION);

System.out.println(choix);

Valeurs possibles :

  • 0 → Oui
  • 1 → Non
  • 2 → Annuler

Cette boîte de dialogue permet de récupérer une valeur saisie.

🔹 Exemple complet avec bouton


JButton btn = new JButton("Envoyer");

btn.addActionListener(e -> {
    JOptionPane.showMessageDialog(null, "Message envoyé !");
});

Exercice d'application

  1. Prendre e formlaire du chapitre précédent.
  2. Ajouter un ActionListener au bouton Valider.
  3. Quand on clique sur Valider, récupérer les valeurs :
    • JTextField Nom
    • JTextField Email
    • JTextField Téléphone
    • JTextArea Message
  4. Écrire des conditions pour vérifier les champs :

Règles de validation :

  • Si le Nom est vide → afficher une alerte d’erreur
  • Si l’Email ne contient pas "@" → alerte d’erreur
  • Si le Téléphone contient moins de 10 chiffres → alerte d’erreur
  • Si le Message est vide → alerte d’erreur

Types d’alertes à utiliser :

  • JOptionPane.ERROR_MESSAGE → pour les erreurs
  • JOptionPane.INFORMATION_MESSAGE → si tout est correct

✅ Si tous les champs sont corrects :

Afficher une alerte :

"Message envoyé avec succès !"

Bouton Annuler :

Quand on clique sur Annuler :

  • Vider tous les champs du formulaire
  • Afficher une alerte : "Formulaire réinitialisé"

💡 Méthodes utiles :

  • textField.getText()
  • textArea.getText()
  • textField.setText("")
  • JOptionPane.showMessageDialog(...)
